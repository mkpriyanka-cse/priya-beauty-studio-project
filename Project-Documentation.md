
# AI Website Copy Generator for Local Businesses

## Project: Priya Beauty Studio

### 1. Business Details
- Business Name: Priya Beauty Studio
- Business Type: Beauty Salon

### 2. Project Objective
The objective of this project is to use Artificial Intelligence to generate professional, attractive and customer-friendly website content for a local beauty salon.

### 3. Tools Used
1. ChatGPT
2. Google Docs
3. GitHub

### 7. Prompt Documentation

**Homepage Prompt:**
Act as a professional website copywriter. Create attractive homepage content for Priya Beauty Studio, including a welcome headline, salon introduction, reasons to choose the salon, main services and a booking call-to-action.

**Services Page Prompt:**
Create a detailed Services Page for Priya Beauty Studio. Include six beauty services, their descriptions and customer benefits.

**CTA Prompt:**
Create an attractive Call-to-Action section for Priya Beauty Studio. Include a catchy booking headline, friendly message, Book Appointment button, Contact Us message and closing sentence.

### 8. Conclusion

This project demonstrates how Artificial Intelligence can help generate professional website content for local businesses. Using ChatGPT, we created homepage content, service descriptions and call-to-action messages for Priya Beauty Studio.
